# Recruitment Tracker Template

A simple structure for tracking candidates through a hiring process in a spreadsheet. This repository holds the layout only, with no real candidate data.

## Why a tracker

A good tracker lets you see at a glance where every candidate is, what is waiting on whom, and how long each stage is taking.

## Columns

| Column | Purpose |
|---|---|
| Candidate ID | A unique reference such as C-001, so names are not needed in reports |
| Date added | When the profile entered the pipeline |
| Role | The position the candidate is being considered for |
| Source | LinkedIn, Naukri, referral, job post, etc. |
| Current company and role | For quick context |
| Total / relevant experience | In years |
| Key skills | The skills that matter for the role |
| Notice period | In days |
| Current CTC / Expected CTC | If your process collects it |
| Location | Current and preferred |
| Screening status | Not started / Done / Hold / Rejected |
| Interview stage | Screening / Technical / Manager / HR / Offer |
| Interview date | Next scheduled round |
| Feedback | Short summary from each round |
| Final status | In process / Offered / Joined / Declined / Rejected |
| Last follow-up | Date of the last contact |
| Next action | What happens next, and who owns it |

## Weekly numbers worth tracking

- Profiles sourced
- Profiles screened
- Interviews scheduled
- Interviews completed
- Offers made and accepted
- Joined
- Average time to fill, from the date the role opens to the date the offer is accepted
- Offer acceptance rate (accepted offers divided by offers made)

Tracking these each week gives you real figures to show your progress.

## Tips

- Update the tracker the same day you speak to a candidate.
- Use drop-down lists for status columns so the data stays consistent.
- Colour-code the final status to read the sheet faster.
- Never put candidate details in a public repository. Store real data only in your company's approved tools.
